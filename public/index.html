Companies Intelligence API — not served from this deployment

This Vercel project compiles the API's TypeScript sources on every push, as a continuous typecheck. It does not run the API.

The service needs a persistent Node process, which this platform does not provide:

  • an Express server bound to a port for the lifetime of the process
  • an always-on pg-boss worker consuming the crawl, discovery, and personalization queues
  • Playwright with a headless Chromium binary for crawling

Requests to /api/*, /health, and /docs are not served here. See the repository's Dockerfile for how the service is actually built and run.

A successful build on this URL means the sources compiled. It does not mean the API is running.
